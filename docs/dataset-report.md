# LIAR Dataset Inspection Report

## Dataset
**LIAR — Fake News Detection Benchmark**  
Introduced in: *William Yang Wang, "Liar, Liar Pants on Fire": A New Benchmark Dataset for Fake News Detection, ACL 2017.*

## Purpose
Used as the initial benchmark dataset for classical machine learning baselines (TF-IDF + Logistic Regression) and subsequent claim analysis.

## Important Scope Limitation
LIAR primarily contains short political claims/statements sourced from PolitiFact fact-checks. The statements have a median length of 17 words and 99 characters. Consequently, this dataset should **not** be described as a general full-length news article dataset; it is specifically a short-statement claim verification benchmark.

## Preprocessing Policy

Text normalization is executed via `backend.app.services.text_cleaner` and `backend.app.services.baseline_data` following a conservative, non-destructive design:

### Operations Performed
1. **Whitespace & Formatting Normalization:** Strips outer edge padding, collapses internal consecutive whitespace/tabs/newlines into a single space, and strips invisible control characters (such as byte-order marks `\ufeff`).
2. **Column Isolation:** Normalization outputs to a separate `clean_statement` column while leaving the original raw `statement` completely unaltered.
3. **Data Integrity:** Strict verification ensures zero row loss across all splits.

### Operations Deliberately Omitted
- **No Global Lowercasing:** Uppercase text (e.g. `BREAKING`, `NASA`) is preserved for red-flag and sensationalism analysis.
- **No Punctuation Stripping:** Expressive punctuation (e.g. `!!!`, `???`, `$`, `%`) is retained.
- **No Stopword Filtering / Lemmatization / Stemming:** Standard vocabulary and grammatical structure are kept intact for linguistic signal evaluation.
